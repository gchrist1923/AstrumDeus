# CMS Astrum Deus Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Mengganti data dummy dengan CMS yang bisa di-login: konten publik di-CRUD dari `/cms`, toggle menu tanpa deploy, modul internal jadwal dan kas ikut tersimpan, situs publik membaca database.

**Architecture:** Custom admin di Next.js App Router (`/cms` dan `/internal`), Prisma + SQLite sebagai sumber data tunggal. Getter publik di `web/lib/content/` berubah dari array hardcoded menjadi query Prisma dengan tanda tangan yang sama, sehingga halaman yang sudah ada hanya ganti sumber data. Autentikasi memakai cookie session httpOnly dan hash kata sandi. Seed mengisi data dummy yang sudah ada supaya UI tidak kosong.

**Tech Stack:** Next.js 16 App Router, Prisma, SQLite, bcryptjs, Vitest.

## Global Constraints

- Sama dengan spec UI: token warna, `lang="id"`, 44px, kontras AA, reduced motion, IDR tanpa desimal, waktu UTC simpan / WIB tampil
- Peran: Admin, Editor, Team Member, Finance sesuai `issue.md`
- Menu mandatory tidak bisa dimatikan
- Entri kas tidak dihapus; koreksi lewat entri pembalik
- Laporan dihitung dari `CashEntry`, bukan tabel terpisah
- Dummy hardcoded tidak boleh jadi sumber produksi setelah task wire-public
- Login lokal seed: `admin@astrumdeus.id` / `astrum-cms-dev` (hanya development)

### Task 1: Prisma, skema, seed

Pasang Prisma, tulis schema semua model PRD, seed dari dummy, `getMenuFlags` async dari DB, `requirePage` memakai flags DB.

### Task 2: Auth session dan login

User + Session, `login`/`logout`, cookie httpOnly, `/login`, proteksi `/cms` dan `/internal`.

### Task 3: Shell admin dan toggle menu

Layout `/cms` dengan nav. Halaman Pengaturan Menu: checkbox hanya untuk item non-mandatory. Public `getMenuFlags` mengikuti perubahan.

### Task 4: CRUD News, Player, Match

Form admin + server actions. Situs publik memakai `cms.ts`.

### Task 5: CRUD Media Kit, Partners, SiteSetting, Contact inbox

Termasuk Home stats (gelar, turnamen, WWCD).

### Task 6: Wire seluruh getter publik ke Prisma

Hapus ketergantungan runtime pada array dummy. Dummy hanya seed.

### Task 7: Schedule Team

Kalender bulan/minggu, CRUD event, peringatan tumpang tindih.

### Task 8: Cash book dan laporan

Dua buku, entri masuk/keluar, koreksi pembalik, laporan harian/bulanan dihitung dari entri, ekspor CSV.

### Task 9: Verifikasi browser

Login admin, ubah berita, matikan Partners, pastikan 404, catat kas, cek laporan.
